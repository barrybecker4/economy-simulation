# Classroom labs

Five locked labs for AP Macro and intro econ. In the app, open **Lessons** next to How to use, or use a shareable link
below. The research app stays at `?` with no `lesson` parameter.

| Lab | Link | Question |
| --- | --- | --- |
| Prices | `?lesson=prices` | Which prices rise while others fall? |
| Interest | `?lesson=interest` | Who sets the interest rate, and what happens to jobs? |
| Deficit | `?lesson=deficit` | What if the government spends more than it taxes? |
| Bitcoin | `?lesson=bitcoin` | What if nobody can print money? |
| Gains | `?lesson=gains` | Who gets the gains when machines do the work? |

Each lab page below has a 15-minute script, student prompts, the cannot-show box, and the seed-1 direction this build
locks in tests (`packages/app/src/session/lessons-direction.test.ts`). When the model changes, re-run that test and
update the answer key.
